# C.O.G Brass Band - Royal Priesthood

Official website for the C.O.G Brass Band (Royal Priesthood).

## 🎺 About

A family of musicians dedicated to worshipping God through the power of sound. From rehearsals to powerful performances, we play with purpose, unity, and passion.

## 🌐 Features

- **Public pages:** Home, About, Music, Events, Merchandise, Birthdays, Contact
- **Member area:** Registration, dashboard, profile management
- **Admin panel:** Manage members, merch, events, songs, announcements, messages, site settings
- **Music:** Debut album "Bophelo Ke Wena" with YouTube promo
- **Email notifications:** Via EmailJS (member approval, event announcements, contact messages)
- **Image uploads:** Via Cloudinary
- **Auto birthday celebrations:** From member profiles

## 🛠 Tech Stack

- **Frontend:** HTML, CSS, vanilla JavaScript
- **Backend:** Firebase Realtime Database + Firebase Authentication
- **Email:** EmailJS
- **Image uploads:** Cloudinary
- **Icons:** Font Awesome
- **Fonts:** Google Fonts (Inter)

## 🚀 Setup

1. Clone the repo
2. Add your Firebase config to `js/firebase-config.js`
3. Add your Cloudinary cloud name to `js/cloudinary-config.js`
4. Serve locally with a web server (e.g., `python -m http.server 8000`)
5. Open `http://localhost:8000`
